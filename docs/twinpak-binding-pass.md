# TwinPak Binding Pass — 7 units

Print one page per unit. Tick as you go. Bring a pen — you write the numbers down **and** type them in.

---

# THE ONE RULE

## Type what the meter reads.

- **Can't read it?** Leave it blank and write down why. Blank is fine. A guess is not.
- **Never** copy a number from the other engine.
- **Never** copy a number from the app.

Same goes for nameplates. **If the plate disagrees with the app, write down what the PLATE says. Do not correct it in the app.** We fix serials from the office, not in the field.

Why it matters: the service countdown is now calculated from what you type. A number nobody read is worse than a blank, because a blank is visibly missing.

---

# READ BOTH METERS. BOTH. INCLUDING ENGINE 1.

This is the one that will feel unnecessary and isn't.

When you split a unit, the hours already in the app get assigned to **Engine 1**. That old number came from the merged record — back when both engines shared one meter reading. **It is not a reading of Engine 1.** Nobody can say which engine it described.

We keep it as history because throwing it away would be worse. But it is **not** Engine 1's current hours.

> **If you skip Engine 1 because "the app already has a number," Engine 1's service countdown keeps running against a number nobody ever read off it.** That is exactly the problem this whole change was built to kill. Don't rebuild it on the last step.

**Engine 1 gets a fresh reading today, off its own meter, same as Engine 2.**

The app will *let* you save without the meters — only the two nameplate ratings are required. That's why the Fleet list flags any engine still missing its own reading (see the last page).

# Before you start

- [ ] Open this on your phone once, so you're on the current version:
      `https://apginvests.github.io/fleet-view/?v=1785463281`
- [ ] **Check you have the toggle** — this is the thing you're about to use, so check for it directly. Open any big-iron unit → **Info** tab → **Edit info** → scroll to the big-iron section. You should see **True TwinPak** with **One engine / TwinPak** buttons.
- [ ] **No True TwinPak toggle = old version.** Force-close the app, reopen it, and check again before you start. Don't work around it.
- [ ] You need **two nameplate kVA ratings per machine**. The app refuses to save without both.

## Which engine is "Engine 1"?

**The housing label decides. Nearly all of these have A and B stencilled on the control panels — use that.**

**The physical label always wins.** Nothing overrides it — not the serial, not the order numbers were typed into the app, not what you'd expect.

- **Genuinely unlabelled machine?** Only then: **hitch end = Engine 1**, rear = Engine 2. Use the hitch, not left/right or road-side — the hitch end is part of the trailer, so it gives the same answer no matter which way the thing got backed in. Write down that you used the hitch rule.

**Units 1 and 2 have two serials in one field.** They follow the same rule as everything else — the panels decide. Separately, **if the engine plates tell you which serial sits on which side, write that down.** It's useful to us. It is not how you decide which engine is Engine 1.

**Do not halve the package rating.** A 1000 kVA TwinPak is not two 500s. Read each plate.

# Checking progress — no need to open each unit

Open **Fleet** and filter to **Big iron**. Scan the cards:

| What the card shows | What it means |
|---|---|
| **`TWINPAK · A/B`** chip (or `1/2`) | Split done. Nameplates are in. |
| **`Gen B needs a meter reading`** chip | Split done, but that engine has **no reading off its own meter**. Not finished. |
| No TwinPak chip at all | **Not converted yet.** |

**A unit is done when it shows the `TWINPAK` chip and NO "needs a meter reading" flag.**

The flag deliberately ignores the old inherited hours — so a unit where Engine 1 was skipped still shows `Gen A needs a meter reading`. That is the whole point: an inherited number is not a reading, and this makes the difference visible from the list.

## If the app refuses to save

**"Read both nameplates — each engine's kVA is required to split a TwinPak."**
That's the app doing its job. It needs both plate ratings before it will split the unit. Nothing else is required — every other field can stay blank.

## If you split the wrong unit

Open it → **Edit info** → **True TwinPak** → **One engine** → Save. Nothing is lost; both plate ratings stay saved for next time. If you'd already logged checks on the engines, it'll ask you to type **TWINPAK** to confirm — that's expected, and it still deletes nothing.
